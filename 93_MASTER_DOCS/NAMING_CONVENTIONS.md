# NAMING CONVENTIONS

## Core Principles

All naming inside BENBENHUB must follow:

- Predictability
- Consistency
- Scalability
- AI readability
- Human readability

---

# Folder Naming Rules

## System Layers

Use numeric prefixes:

00_
01_
02_

Example:
00_VISION
01_ARCHITECTURE
03_CORE_KERNEL

---

# Governance Layers

Use 90+ namespace:

90_AI_MEMORY
91_DECISIONS
93_MASTER_DOCS

---

# File Naming Rules

Use:

UPPERCASE_WITH_UNDERSCORES

Examples:

PROJECT_BIBLE.md
SECURITY_MODEL.md
API_TEMPLATE.md

---

# Forbidden Naming

Do NOT use:

- spaces
- random casing
- Arabic names
- vague names
- version chaos
- temporary labels

Forbidden examples:

final_v2.md
new file.md
notes.md
important.md

---

# Script Naming Rules

Use ordered prefixes:

00_
01_
02_

Examples:

00_initialize_vault.ps1
01_create_structure.ps1

---

# AI Memory Rules

Session files must contain:

- date
- topic
- context type

Example:

2026-05-06_KERNEL_REVIEW.md

---

# Architectural Principle

Names must remain stable long-term.

Renaming core structures without ADR is forbidden.
